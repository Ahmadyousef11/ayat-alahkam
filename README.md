# موقع دورة: آيات الأحكام من سورة البقرة

موقع تعليمي ثابت (HTML + CSS + JavaScript) بلا أي إطار عمل أو اعتماديات.

---

## التشغيل محليًّا

الموقع يعمل بطريقتين:

**١. بالنقر المزدوج على `index.html`** — يعمل مباشرة لأن بيانات الدورة والتوقيتات مضمّنة في ملفات `.js`.
(ملاحظة: ملفات الترجمة `.vtt` لا تُحمَّل بهذه الطريقة بسبب قيود المتصفح على `file://`.)

**٢. عبر خادم محلي** — وهي الطريقة الكاملة (تُظهر التفريغ المتزامن):

انقر **`serve.bat`** نقرًا مزدوجًا، أو من الطرفية:

```bash
cd "مجلد الموقع"
python serve.py
```

ثم افتح: <http://localhost:8000>

> **مهم:** لا تستخدم `python -m http.server` — فهو لا يدعم ترويسة **Range**،
> وبدونها يمنع المتصفحُ القفزَ داخل الملف الصوتي، فيتعذّر التقديم والتأخير
> والانتقال إلى شريحة موقّتة. ملف `serve.py` المرفق يضيف هذا الدعم
> (يرد بـ `206 Partial Content`).

## بنية المجلدات

```
index.html          الصفحة الرئيسية (شبكة المجالس التسعة)
lecture.html        صفحة المجلس (?id=1 … 9)
sync.html           محرّر مزامنة الشرائح
assets/css/         التنسيقات
assets/js/          السكربتات
data/course.json    بيانات الدورة (مصدر التحرير)
data/course.js      نفس البيانات لتعمل بلا خادم — أعد توليده بعد أي تعديل
data/timings/       توقيت الشرائح لكل مجلس (JSON)
data/timings.js     نسخة مجمّعة لتعمل بلا خادم
audio/lecN.mp3      الملفات الصوتية
slides/N/NN.webp    صور الشرائح
pdf/lecN.pdf        العروض للتحميل
subs/lecN.vtt       التفريغ المتزامن (٩ ملفات جاهزة)
serve.py            خادم محلي يدعم Range — لازم للقفز في الصوت
serve.bat           تشغيل الخادم بنقرة على ويندوز
```

بعد تعديل `data/course.json` أو ملفات `data/timings/` **يكفي إعادة تشغيل `serve.bat`** —
فالخادم يعيد توليد `data/course.js` و `data/timings.js` تلقائيًّا عند كل تشغيل،
ويطبع رسالة خطأ واضحة إن كانت صياغة JSON غير سليمة.

للتوليد يدويًّا دون تشغيل الخادم: `python tools/build_data.py`

📘 **للتعديل اليدوي خطوة بخطوة، انظر: [دليل التعديل.md](دليل%20التعديل.md)**

## ضبط مزامنة الشرائح

التوقيتات الحالية **مستخرجة آليًّا** بمطابقة عبارات كل شريحة على التفريغ الموقّت،
ودقّتها جيدة لكنها ليست مثالية. لضبط أي شريحة بدقة:

1. افتح `sync.html`
2. اختر المجلس، وشغّل الصوت (يمكنك رفع السرعة إلى ٢× أو ٣×)
3. كلّما انتقل الشيخ لشريحة جديدة اضغط الزر الذهبي أو مفتاح **M**
4. اضغط «تنزيل الملف» واحفظه في `data/timings/lecN.json`
5. أعد تشغيل `python tools/build_data.py`

### دورة التعديل — ثلاث خطوات

| | ماذا تفعل |
|---|---|
| **١. عدّل** | افتح الملف بمحرّر نصوص (Notepad++ أو VS Code) واحفظ |
| **٢. جرّب محليًّا** | انقر `serve.bat` ← <http://localhost:8000> ← **Ctrl + Shift + R** |
| **٣. انشر** | انقر **`update-site.bat`** نقرًا مزدوجًا |

`update-site.bat` يجمع كل ما غيّرته ويرفعه، ويعيد المحاولة تلقائيًّا إن انقطع
الاتصال. يظهر التحديث على الرابط الحيّ خلال دقيقة تقريبًا (اضغط
**Ctrl + Shift + R** في المتصفح لتجاوز الذاكرة المؤقتة).

> يمكن تخطّي الخطوة ٢ في التعديلات النصية البسيطة.

> **تنبيه:** لا تُنشئ ملفات فوق ١٠٠ ميجابايت — هذا حدّ GitHub للملف الواحد.
> ملفاتنا الصوتية ١٩–٢٣ ميجا، فهي بأمان.

## الصوت

كل مجلس بصيغتين، والمتصفح يختار تلقائيًّا:

| | الصيغة | الحجم | الدعم |
|---|---|---|---|
| الأساسية | Opus ‏٢٠ ك.ب/ث | ١٥–١٩ ميجا | كل المتصفحات الحديثة |
| الاحتياطية | MP3 ‏٢٤–٢٨ ك.ب/ث | ١٩–٢٣ ميجا | الجميع بلا استثناء |

**المعالجة المطبَّقة** (من الملفات الأصلية لا من نسخة مضغوطة):

- قطع الدمدمة والضجيج تحت ٨٥ هرتز
- تلطيف الصفير (deesser)
- تسوية ديناميكية ترفع أصوات الطلبة البعيدة إلى مستوى الشيخ
- ضبط الجهارة على معيار البودكاست ‎−١٦ LUFS
- حاجز ذروة يمنع التشويه (كان الأصل يبلغ ‎٠ ديسيبل ويقصّ)

النتيجة: نسبة الإشارة إلى الضجيج تحسّنت نحو ١١ ديسيبل، ومدى الجهارة
انضبط من ٧٫٨ إلى ٣٫٧ وحدة — أي صوت مريح ومستوٍ طوال المجلس.

## المزايا المنفَّذة

- شبكة بطاقات متجاوبة مع تأثيرات حركية
- مشغّل صوتي كامل: تشغيل/إيقاف، شريط تقدّم قابل للسحب، مؤشر التحميل، التحكم بالصوت والكتم
- تشغيل تلقائي عند فتح صفحة المجلس (يحترم سياسة المتصفح ولا يفشل إن مُنع)
- مزامنة الشرائح تلقائيًّا عبر حدث `timeupdate` مع بحث ثنائي على التوقيتات
- التقليب اليدوي يدخل «وضعًا يدويًّا» حرًّا مع زر ظاهر للعودة إلى المزامنة
- لوحة تفريغ كامل: تمييز المقطع الجاري، والنقر على أي سطر ينقل الصوت، وبحث فوري
- التفريغ المتزامن من ملفات WebVTT
- سرعات التشغيل: ٠.٧٥× · ١× · ١.٢٥× · ١.٥× · ٢×
- قفز ١٥ ثانية للأمام/الخلف · اختصارات لوحة المفاتيح (مسافة، أسهم)
- الوضع الليلي/النهاري مع حفظ التفضيل
- تحميل الصوت MP3 والعرض PDF
- تصميم متجاوب كامل (جوال · لوحي · سطح مكتب)
- دعم `prefers-reduced-motion` وسمات ARIA
