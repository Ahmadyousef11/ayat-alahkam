# التفريغ المتزامن (Subtitles)

ضع هنا ملفات `.vtt` بأسماء: `lec1.vtt` … `lec8.vtt`
وسيلتقطها الموقع تلقائيًّا ويعرض النص متزامنًا أسفل الشريحة.

## كيف تحصل على ملف VTT عربي موقّت مجانًا

أسهل طريقة مجرّبة وبلا حدّ لطول الملف:

1. ارفع الملف الصوتي إلى **YouTube** كفيديو **غير مُدرَج (Unlisted)**
   (يكفي تحويله لفيديو بصورة ثابتة، أو ارفع الـ MP3 مباشرة عبر أدوات الرفع التي تقبل الصوت).
2. انتظر حتى تُنتج المنصّة الترجمة التلقائية بالعربية (عادةً دقائق).
3. من **YouTube Studio → الترجمة (Subtitles) → العربية (تلقائية) → تنزيل**، أو استخدم أي أداة
   تنزيل ترجمات تدعم صيغة VTT.
4. أعد تسمية الملف إلى `lecN.vtt` وضعه في هذا المجلد.

> الصيغة المطلوبة هي WebVTT القياسية، مثال:
>
> ```
> WEBVTT
>
> 00:00:03.120 --> 00:00:07.480
> بسم الله الرحمن الرحيم والحمد لله رب العالمين
> ```

ملف `.srt` يمكن تحويله لـ `.vtt` بإضافة سطر `WEBVTT` في أوله واستبدال الفاصلة `,` بنقطة `.` في التوقيتات.
